# পুরানবাজার (PuranBazar) — Online Marketplace

**পুরানবাজার (PuranBazar)** হলো বাংলাদেশের একটি আধুনিক, দ্রুতগতির এবং নিরাপদ অনলাইন সেকেন্ডহ্যান্ড মার্কেটপ্লেস ও ক্লাসিফায়েড বিজ্ঞাপন প্ল্যাটফর্ম। ক্রেতা এবং বিক্রেতা উভয়ই সহজে মোবাইল বা কম্পিউটার থেকে পণ্য ক্রয়-বিক্রয়, বিজ্ঞাপন পোস্ট, ইন-অ্যাপ বিকাশ/নগদ গেটওয়ে দিয়ে বিজ্ঞাপন বুস্টিং, সরাসরি চ্যাটিং এবং প্রতারণা রোধক সুরক্ষা ব্যবহার করতে পারেন।
