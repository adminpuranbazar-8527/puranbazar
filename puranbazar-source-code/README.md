# পুরানবাজার (PuranBazar) — Online Marketplace

**পুরানবাজার (PuranBazar)** হলো বাংলাদেশের একটি আধুনিক, দ্রুতগতির এবং নিরাপদ অনলাইন সেকেন্ডহ্যান্ড মার্কেটপ্লেস ও ক্লাসিফায়েড বিজ্ঞাপন প্ল্যাটফর্ম। ক্রেতা এবং বিক্রেতা উভয়ই সহজে মোবাইল বা কম্পিউটার থেকে পণ্য ক্রয়-বিক্রয়, বিজ্ঞাপন পোস্ট, ইন-অ্যাপ বিকাশ/নগদ গেটওয়ে দিয়ে বিজ্ঞাপন বুস্টিং, সরাসরি চ্যাটিং এবং প্রতারণা রোধক সুরক্ষা ব্যবহার করতে পারেন।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **বিজ্ঞাপন ব্রাউজিং ও আধুনিক সার্চ ফিল্টারিং:**
   - ৬৪টি জেলা ও ৮টি বিভাগ ভিত্তিক ফিল্টারিং
   - ক্যাটাগরি ও সাব-ক্যাটাগরি নেভিগেশন (মোবাইল, ল্যাপটপ, বাইক, আসবাবপত্র, ফ্যাশন ইত্যাদি)
   - মূল্য ও কন্ডিশন অনুযায়ী নিখুঁত অনুসন্ধান
2. **বিজ্ঞাপন পোস্টিং ও ওটিপি ভেরিফিকেশন:**
   - মাল্টি-স্টেপ পোস্ট অ্যাড উইজার্ড
   - মোবাইল নম্বর ভেরিফিকেশন
   - প্যাকেজ নির্বাচন (ফ্রি, ফিচার্ড ৳৪৯, প্রিমিয়াম ৳৯৯, টপ লিস্টিং ৳১৯৯)
3. **ইন-অ্যাপ বিকাশ, নগদ ও রকেট পেমেন্ট গেটওয়ে সিমুলেশন:**
   - বিজ্ঞাপন পোস্ট করার সময় বা পরবর্তীতে যেকোনো সময় ১-ক্লিকে বুস্টিং
   - অফিসিয়াল ব্র্যান্ডেড চেকআউট (bKash `#E2136E`, Nagad `#F7941D`, Rocket `#8C3494`)
   - ২-৫ মিনিটের ওটিপি ভেরিফিকেশন টাইমার ও ১-ক্লিক অটোফিল
   - সিকিউর পিন এন্ট্রি ও ইউনিক TrxID সহ ডিজিটাল মানি রিসিট
4. **ইউজার একাউন্ট ও পাসওয়ার্ড রিকভারি:**
   - মোবাইল নম্বর বা ইমেইল দিয়ে সহজে লগইন ও রেজিস্ট্রেশন
   - পাসওয়ার্ড ভুলে গেলে মোবাইল SMS বা ইমেইলে ৫ মিনিটের ওটিপি পাঠিয়ে নতুন পাসওয়ার্ড রিসেট
5. **আমার বিজ্ঞাপন ও প্রোফাইল ড্যাশবোর্ড:**
   - পোস্টকৃত বিজ্ঞাপনের লাইভ স্ট্যাটাস (অনুমোদিত/অপেক্ষমাণ/বাতিল)
   - সরাসরি নিজের বিজ্ঞাপন দেখার পেজ থেকে বা ড্যাশবোর্ড থেকে বুস্ট করার সুবিধা
6. **কনফিডেনশিয়াল সিক্রেট এডমিন পোর্টাল (`/` থেকে গোপন কিবোর্ড শর্টকাট বা ফুটার কি-হোল):**
   - রোল-বেসড অ্যাক্সেস কন্ট্রোল (Super Admin, Moderator)
   - বিজ্ঞাপন অনুমোদন ও বাতিল
   - অভিযোগ তদন্ত ও প্রতারণা সমাধান
   - গুগল এডসেন্স, ফিচার্ড বিজ্ঞাপন ও এসক্রো রাজস্ব হিসাব
   - সুপার এডমিনের জন্য বাংলাদেশি ব্যাংক ও এমএফএস পেআউট সিস্টেম
7. **১০০% রেসপনসিভ ও ডার্ক মোড সাপোর্ট:**
   - মোবাইল, ট্যাবলেট ও ডেস্কটপের জন্য অপ্টিমাইজড UI

## 🚀 লোকাল ডেভেলপমেন্ট সেটআপ (Local Setup)

যেকোনো নতুন ডেভেলপার এই প্রজেক্টটি খুব সহজেই ক্লোন বা ডাউনলোড করে রান করতে পারবেন:

```bash
# ১. ডিপেনডেন্সি ইনস্টল করুন
npm install

# ২. লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন (Port 3000)
npm run dev

# ৩. ব্রাউজারে ওপেন করুন
http://localhost:3000
```

### অন্যান্য কমান্ডসমূহ:
```bash
# প্রোডাকশনের জন্য বিল্ড তৈরি (Output: /dist)
npm run build

# বিল্ড ফাইল প্রিভিউ দেখা
npm run preview

# টাইপস্ক্রিপ্ট লিন্টিং যাচাই
npm run lint

# সম্পূর্ণ সোর্স কোড ও প্রোডাকশন জিপ বান্ডেল তৈরি
npm run bundle
```

## 🌐 কাস্টম ডোমেইন ও হোস্টিং পাবলিশিং গাইড (Quick Deploy)

### ১. Vercel-এ ১-ক্লিক ডিপ্লয় (সর্বোত্তম ও বিনামূল্যে SSL সহ):
1. GitHub-এ কোড পুশ করুন বা সোর্স কোড ফোল্ডারটি [Vercel](https://vercel.com)-এ আপলোড করুন।
2. Framework হিসেবে **Vite** সিলেক্ট থাকবে।
3. **Deploy** বাটনে ক্লিক করুন।
4. Settings > Domains থেকে আপনার কেনা ডোমেইন (যেমন: `puranbazar.com`) যুক্ত করুন।
5. DNS সেটিংসে Vercel-এর দেওয়া `A Record` (`76.76.21.21`) এবং `CNAME Record` (`cname.vercel-dns.com`) অ্যাড করুন।

### ২. cPanel / Shared Hosting (Namecheap, XeonBD, DianaHost ইত্যাদি):
1. `npm run build` রান করুন (বা ডাউনলোড করা `puranbazar-production-dist.zip` ফাইলটি নিন)।
2. cPanel-এ লগইন করে **File Manager** > **public_html**-এ যান।
3. সমস্ত ফাইল ও ফোল্ডার (`index.html`, `assets/`, `.htaccess`, `_redirects`) `public_html`-এ আপলোড করে Unzip করুন।
4. সাইট স্বয়ংক্রিয়ভাবে চালু হয়ে যাবে!
